
Учебный проект приложения **Playlist Maker** по курсу Android-разработки (спринты 3–6).

## О проекте

Приложение для поиска музыкальных треков, просмотра списка результатов и управления настройками.

Реализованный функционал:
- Главный экран с навигацией по разделам («Поиск», «Плейлисты», «Избранное», «Настройки»).
- Экран настроек с переключателем тёмной темы и действиями через неявные `Intent` («Поделиться приложением», «Написать разработчикам», «Пользовательское соглашение»).
- Экран поиска треков с полем ввода, кнопкой очистки, индикатором загрузки, списком найденных треков (`LazyColumn`) и обработкой состояний экрана (`SearchState`).
- Разделение архитектуры на слои `data`, `domain` и `ui`, внедрение зависимостей через `Creator` и Koin.

## Стек

- Kotlin
- Jetpack Compose (Material 3, Navigation Compose)
- ViewModel, StateFlow, Kotlin Coroutines
- Koin
- Gradle (Kotlin DSL), `minSdk = 29`, `compileSdk = 35`

## Запуск проекта

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Igor3675/yandex-practicum-mobile-development.git
   ```
2. Открыть папку проекта в Android Studio (JDK 17+).
3. Дождаться синхронизации Gradle и запустить конфигурацию `app` на эмуляторе или устройстве.

Сборка через консоль:
```bash
./gradlew assembleDebug testDebugUnitTest
```
